# ИИ система работы с документами

## Структура проекта
```
 /agent-system-v2
   |-- backend
        |-- app
             |-- models
             |-- services
             |-- api
             |-- database
```

## Компоненты системы

 * Работа с документами - загрузка, разбиение на куски, сохранение в векторную БД с пометками, получение данных
 * Диалоги  - создать диалог, получить список сообщение в диалоге, удалить диалог
 * Сообщения - отправка сообщений, получение сообщений
 * Авторизация - регистрация, авторизация
 

## Технические требования

 * Python 3.9+ - https://www.python.org/ftp/python/3.10.10/python-3.10.10-amd64.exe
 * PostgreSQL 14+ - 

### Что установить

 * Установить Python версию не ниже 3.9. 
 * Установить PostgreSQL сервер, не ниже 14. 
 * Для написания кода Visual Studio Code.
